# Application_Expert_Plastic

Weighbridge system of Expert Plastic Sdn Bhd (Visual C++ 6 / MFC on the shared wlib32, winlib and wtlib32 libraries). Main menu: Weighing, Adjustment/Invoicing, Table, Report, Utility. Handles receiving and despatch tickets with camera photos, public weighing, an I/C (identity card) register, stock adjustment, sales and purchase invoices with paid/unpaid status, and ticket export to the accounting tables.
